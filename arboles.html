¿Cómo usar Árboles Binarios?


Insertar

Escribe un número y presiona "Insertar" para agregarlo al árbol de búsqueda.


Recorridos

Genera los órdenes Preorder, Inorder y Postorder. Puedes animarlos para ver el camino o copiarlos en formato de lista para reconstruir.


Reconstruir

Crea un árbol exacto pegando el Inorder y un segundo recorrido (Pre o Post).


Archivos

Exporta tu árbol en JSON para cargarlo después o en PNG para guardarlo como imagen.
